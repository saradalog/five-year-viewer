# 全銘柄5年ビューア

他のAIで編集するときは、まず `AGENTS.md` を読ませてください。

日本・米国・香港の全銘柄について、直近5期の売上高・利益・EPS・有利子負債・時価総額・株価と、理論株価・適正株価をスマホで見て、A〜Dで評価するWebアプリ（PWA）です。GitHub Pages で配信し、ホーム画面に追加して使います。

- このリポジトリには画面のコードだけを置いています。データと評価は、Googleスプレッドシートに付けた Apps Script から、合言葉を知っている人だけが受け取れます。
- データは端末内（IndexedDB）に保存されるので、2回目からはすぐ開き、オフラインでも見られます。
- A〜Dの評価は、スプレッドシート「全銘柄_直近5年_財務と株価_日米中」の「評価」タブに保存され、どの端末からでも同じものが見られます。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（一覧・銘柄詳細・設定。HTML・CSS・JS 1枚、ビルド不要） |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |

## はじめて使うとき

1. Apps Script をデプロイする（下）。
2. アプリを開き、右上の「設定」でウェブアプリのURL（`…/exec`）と合言葉を入れる。

## Apps Script

コード（`Code.gs`）は公開のこのリポジトリには置きません。持ち主のPCの `jquants_data/_scripts/five_year/apps_script/Code.gs` にあります。

## データの更新

持ち主がClaudeに「5年ビューアを最新にして」と頼むと、PCの `jquants_data` から作り直したデータ（`fyv_jp.json.gz` など）がGoogleドライブのフォルダ「全銘柄5年ビューア_データ」に入ります。アプリは次に開いたとき、新しいデータを自動で受け取ります。
